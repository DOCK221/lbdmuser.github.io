# Burger Coffee — Site web

Site premium immersif pour **Burger Coffee**, restaurant-terrasse à Saly, Sénégal.

## Lancer en local

Ouvrir `index.html` dans un navigateur, ou :

```bash
python3 -m http.server 8000
```

Puis visiter `http://localhost:8000`.

## Structure

- `index.html` — page unique SEO-friendly
- `css/styles.css` — design premium responsive
- `js/main.js` — animations, slider, filtres, parallaxe
- `robots.txt` / `sitemap.xml` — référencement
