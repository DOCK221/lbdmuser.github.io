# Nid de Plumes — site officiel

Site e-commerce premium de **Nid de Plumes**, marque sénégalaise de linge hôtelier haut de gamme.

## Stack

- Next.js (App Router) · TypeScript · Tailwind CSS
- Framer Motion · Lucide Icons

## Lancer en local

```bash
npm install
npm run dev
```

## Configuration

Copier `.env.example` vers `.env.local` :

```
NEXT_PUBLIC_WHATSAPP_NUMBER=
NEXT_PUBLIC_SITE_URL=
NEXT_PUBLIC_INSTAGRAM_URL=
```

Le numéro WhatsApp n’est pas renseigné volontairement. Dès qu’il est disponible, renseigner `NEXT_PUBLIC_WHATSAPP_NUMBER` (indicatif pays, chiffres uniquement, ex. `221XXXXXXXXX`). Les boutons WhatsApp fonctionnent déjà : sans numéro, WhatsApp s’ouvre avec le message prérempli.

## Contenu commercial

Aucun prix, dimension non fournie, composition non confirmée ou historique de marque n’a été inventé. Les tarifs s’affichent « Prix sur demande ». Le stock est indiqué comme disponible à Dakar.
