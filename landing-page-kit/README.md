## ⚡ Quick Start

### 1. Installation

```bash
# Clone or download this repository
cd landing-page-kit

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the default SaaS template.

### 2. View All Templates

- SaaS/AI: `http://localhost:3000`
- Mobile App: `http://localhost:3000/templates/mobile-app`
- Startup: `http://localhost:3000/templates/startup`
- Dev Tool: `http://localhost:3000/templates/dev-tool`
- Course: `http://localhost:3000/templates/course`

### 3. Customize

Edit the components in `/components` or pages in `/app` to match your brand and content.

See [CUSTOMIZATION.md](./CUSTOMIZATION.md) for detailed instructions.

## 🚀 Deployment

### Deploy to Vercel (Recommended)

1. Push your code to GitHub
2. Import your repository on [Vercel](https://vercel.com)
3. Vercel will automatically detect Next.js and deploy

Or use the Vercel CLI:

```bash
npm install -g vercel
vercel
```

### Build for Production

```bash
npm run build
npm start
```

## 🎨 Customization

### Change Colors

Edit `app/globals.css` to customize the color scheme:

```css
:root {
  --primary: 240 5.9% 10%;
  --background: 0 0% 100%;
  /* ... more variables */
}
```

### Change Fonts

Edit `app/layout.tsx` to use your preferred fonts from Google Fonts.

### Add Your Content

1. Edit text content in component files
2. Replace placeholder images in `/public`
3. Update metadata in `app/layout.tsx`

See [CUSTOMIZATION.md](./CUSTOMIZATION.md) for detailed instructions.
