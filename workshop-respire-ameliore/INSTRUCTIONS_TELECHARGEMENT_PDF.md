## ❓ FAQ - Problèmes courants

### Q1 : Les couleurs ne s'affichent pas dans le PDF
**Solution** : Vérifiez que vous avez coché **"Graphiques d'arrière-plan"** dans les paramètres d'impression.

### Q2 : Le PDF fait plus de 31 pages (coupures)
**Solution** : 
- Réglez les **marges à "Aucune"**
- Réglez l'**échelle à 100%** (pas 90% ou 110%)
- Désactivez les en-têtes/pieds de page

### Q3 : La police ne s'affiche pas correctement
**Solution** : 
- Le navigateur charge automatiquement les polices Google Fonts (Montserrat, Open Sans)
- Si vous êtes hors ligne, utilisez Chrome qui gère mieux les polices web

### Q4 : Je veux modifier le contenu avant conversion
**Solution** : 
- Ouvrez `PRESENTATION_ORALE_PDF.html` dans un éditeur de texte (Notepad++, VS Code, Sublime Text)
- Modifiez directement le HTML (attention, gardez la structure intacte)
- Sauvegardez et rouvrez dans le navigateur

### Q5 : Le PDF est trop lourd (> 10 Mo)
**Solution** : 
- Après génération, utilisez un compresseur PDF en ligne : https://www.ilovepdf.com/compress_pdf
- Ou https://smallpdf.com/compress-pdf
