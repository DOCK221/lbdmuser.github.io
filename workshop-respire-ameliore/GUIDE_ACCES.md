## 🔍 Comment lire les fichiers Markdown (.md) ?

Les fichiers ont l'extension `.md` (Markdown). Voici comment les lire :

### Option 1 : Sur GitHub (Recommandé, rendu parfait)
- Les fichiers sont automatiquement rendus avec la mise en forme
- C'est la meilleure façon de les lire (tableaux, listes, titres formatés)

### Option 2 : Dans un éditeur Markdown
- **VS Code** : Ouvrir le fichier + Clic droit + "Open Preview" (Ctrl+Shift+V)
- **Typora** : Application dédiée (https://typora.io/)
- **MarkText** : Gratuit et open-source (https://marktext.app/)

### Option 3 : Dans un éditeur de texte simple
- Notepad++ (Windows)
- TextEdit (Mac)
- Gedit (Linux)
- Le fichier est lisible même sans mise en forme

### Option 4 : Convertir en PDF
- Utiliser Pandoc : `pandoc fichier.md -o fichier.pdf`
- Ou un convertisseur en ligne : https://www.markdowntopdf.com/

## 💡 Conseils pratiques

### Pour bien s'organiser

1. **Imprimez la checklist** de SYNTHESE_AMELIORATIONS.md
2. **Créez un dossier** sur votre ordinateur : `Workshop_RESPIRE_Rattrapages/`
3. **Mettez tous les fichiers dedans**
4. **Utilisez un timer** : Pomodoro 25 min de travail + 5 min de pause
5. **Cochez au fur et à mesure** les étapes accomplies

### Pour la présentation PowerPoint

1. **Sauvegardez régulièrement** (Ctrl+S toutes les 5 minutes)
2. **Créez une copie de secours** (Version 1, Version 2, etc.)
3. **Utilisez les modèles de slides** fournis dans PRESENTATION_AMELIOREE.md
4. **Ne passez pas trop de temps sur le design** : Contenu > Design

### Pour l'oral

1. **Enregistrez-vous** avec votre webcam/téléphone
2. **Regardez-vous** : Posture, regard, débit
3. **Chronométrez chaque répétition** : 15-20 min maximum
4. **Préparez des réponses courtes** : 1-2 min par question max
