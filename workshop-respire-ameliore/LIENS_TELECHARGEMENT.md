## 📄 COMMENT CONVERTIR EN PDF ?

Les fichiers sont au format Markdown (.md). Voici comment les convertir en PDF :

### Méthode 1 : Convertisseur en ligne (Plus facile) ⭐

**1. Téléchargez le fichier .md**
**2. Allez sur un convertisseur en ligne :**
- https://www.markdowntopdf.com/
- https://md2pdf.netlify.app/
- https://www.browserling.com/tools/markdown-to-pdf

**3. Uploadez le fichier .md**
**4. Téléchargez le PDF généré**

### Méthode 2 : Avec Google Chrome (Depuis GitHub)

**1. Ouvrez le fichier sur GitHub** (liens "Lire sur GitHub" ci-dessus)
**2. Le fichier s'affiche avec la mise en forme**
**3. Clic droit → Imprimer (ou Ctrl+P)**
**4. Destination → Enregistrer au format PDF**
**5. Téléchargez votre PDF**

### Méthode 3 : Avec Pandoc (Si vous avez un terminal)

```bash
# Installer Pandoc (une fois)
# Windows: https://pandoc.org/installing.html
# Mac: brew install pandoc
# Linux: sudo apt-get install pandoc

# Convertir un fichier
pandoc CAHIER_DES_CHARGES_RESPIRE_B2B.md -o CAHIER_DES_CHARGES_RESPIRE_B2B.pdf

# Convertir tous les fichiers
for file in *.md; do pandoc "$file" -o "${file%.md}.pdf"; done
```

### Méthode 4 : Avec VS Code + Extension

**1. Installer VS Code** : https://code.visualstudio.com/
**2. Installer l'extension "Markdown PDF"**
**3. Ouvrir le fichier .md dans VS Code**
**4. Clic droit → Markdown PDF: Export (pdf)**
